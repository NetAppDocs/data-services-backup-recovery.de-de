= Bekannte Einschränkungen mit NetApp Backup and Recovery für Oracle Database-Workloads
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Die aktuellen Einschränkungen und nicht unterstützten Aktionen für Oracle Database Workloads in NetApp Backup and Recovery werden aufgeführt.

Die folgenden Aktionen werden für Oracle Database-Workloads in der Vorabversion von NetApp Backup and Recovery nicht unterstützt:

* In der Backup and Recovery-Vorabversion für die lokale Bereitstellung der NetApp Console werden Backups in Objektspeicher nur für ONTAP S3 und StorageGRID Ziele unterstützt. Backup-Archivierung ist in dieser Vorabversion nicht unterstützt.
* Offline-Backups
