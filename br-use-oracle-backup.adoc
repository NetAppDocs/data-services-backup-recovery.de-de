= Sichern Sie Oracle-Datenbank-Workloads mit NetApp Backup und Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Oracle Datenbank-Schutzgruppen oder einzelne Datenbanken von lokalen ONTAP Systemen können mit NetApp Backup und Recovery gesichert werden. Backups werden an Cloud-Speicher wie Amazon S3, NetApp StorageGRID, Microsoft Azure Blob Storage oder ONTAP S3 gesendet.


NOTE: Um Schutzgruppen oder einzelne Datenbanken nach einem Zeitplan zu sichern, erstellen Sie Richtlinien, die Sicherungs- und Wiederherstellungsvorgänge verwalten. Sehenlink:br-use-policies-create.html["Erstellen von Richtlinien"] Anweisungen hierzu finden Sie unter.

* Erstellen Sie Schutzgruppen, um Backup- und Restore-Vorgänge für eine Gruppe von Ressourcen zu verwalten. Siehe link:br-use-kvm-protection-groups.html["Erstellen und Verwalten von Schutzgruppen für Oracle-Datenbank-Workloads mit NetApp Backup und Recovery"] für weitere Informationen.
* Eine bedarfsgesteuerte Sicherung einer Schutzgruppe erstellen.
* Eine bedarfsgesteuerte Datensicherung einer Datenbank erstellen.




[[create-an-on-demand-backup-of-a-protection-group]]
== On-Demand-Backup einer Schutzgruppe erstellen

Vor Systemänderungen ein Backup bei Bedarf erstellen, um die Daten zu schützen.

*Erforderliche Konsolenrolle* Superadministrator für Backup und Wiederherstellung oder Backupadministratorrolle für Backup und Wiederherstellung. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Erfahren Sie mehr über die Zugriffsrollen der NetApp Console für alle Dienste"^] .

.Schritte
. Wählen Sie im NetApp Console *Schutz > Sicherung und Wiederherstellung*.
. Wählen Sie unter *Workloads* die Kachel *Oracle* aus.
. Wählen Sie *Inventar*.
. Wählen Sie eine Arbeitslast aus, um die Schutzdetails anzuzeigen.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Details anzeigen*.
. Die Registerkarte *Schutzgruppen* auswählen.
. Wählen Sie die Schutzgruppe aus, die Sie sichern möchten.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Jetzt sichern*.
+

NOTE: NetApp Backup and Recovery verwendet für die Sicherungs- und die Schutzgruppe dieselbe Richtlinie.

. Wählen Sie die Zeitplanstufe aus.
. Wählen Sie *Sichern*.

== Eine bedarfsgesteuerte Sicherung einer Datenbank erstellen

Vor Systemänderungen ein Backup bei Bedarf erstellen, um die Daten zu schützen.

*Erforderliche Konsolenrolle* Superadministrator für Backup und Wiederherstellung oder Backupadministratorrolle für Backup und Wiederherstellung. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Erfahren Sie mehr über die Zugriffsrollen der NetApp Console für alle Dienste"^] .

.Schritte
. Wählen Sie im NetApp Console *Schutz > Sicherung und Wiederherstellung*.
. Wählen Sie unter *Workloads* die Kachel *Oracle* aus.
. Wählen Sie *Inventar*.
. Wählen Sie eine Arbeitslast aus, um die Schutzdetails anzuzeigen.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Details anzeigen*.
. Wählen Sie die Registerkarte *Datenbanken*.
. Wählen Sie die Datenbank aus, die Sie sichern möchten.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Jetzt sichern*.
. Wählen Sie die Zeitplanstufe aus.
. Wählen Sie *Sichern*.
