= Sichern Sie KVM-Workloads mit NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
KVM-Schutzgruppen von lokalen ONTAP-Systemen können in Amazon Web Services, Azure NetApp Files oder StorageGRID gesichert werden. Beim Sichern einer Schutzgruppe sichert NetApp Backup and Recovery die VMs und Speicherpools dieser Gruppe und speichert die Sicherung in einem Objektspeicher im öffentlichen oder privaten Cloud-Konto.


NOTE: Um geplante Backups durchzuführen, werden Richtlinien erstellt, die Backup- und Restore-Vorgänge steuern. Siehe link:br-use-policies-kvm-create.html["KVM Schutzrichtlinien erstellen"] für Anweisungen.

* Erstellen Sie Schutzgruppen, um Backup- und Recovery-Vorgänge für eine Gruppe von Ressourcen zu verwalten. Siehe link:br-use-kvm-protection-groups.html["KVM-Schutzgruppen in NetApp Backup and Recovery verwalten"] für weitere Informationen.

== Sichern Sie Schutzgruppen jetzt mit einem On-Demand-Backup

Eine On-Demand-Datensicherung kann sofort durchgeführt werden, wenn Änderungen bevorstehen und zuvor eine aktuelle Sicherung benötigt wird.

*Erforderliche Konsolenrolle* Superadministrator für Backup und Wiederherstellung oder Backupadministratorrolle für Backup und Wiederherstellung. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Erfahren Sie mehr über die Zugriffsrollen der NetApp Console für alle Dienste"^] .

.Schritte
. Wählen Sie im NetApp Console *Schutz > Sicherung und Wiederherstellung*.
. Wählen Sie in der KVM-Kachel *Erkennen und verwalten* aus.
. Wählen Sie *Inventar*.
. Eine Arbeitslast kann ausgewählt werden, um die Schutzdetails anzuzeigen.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Details anzeigen*.
. Die Registerkarte *Schutzgruppen*, *Datenspeicher* oder *Virtuelle Maschinen* auswählen.
. Wählen Sie die Schutzgruppe aus, die Sie sichern möchten.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Jetzt sichern*.
+

NOTE: Die auf die Sicherung angewendete Richtlinie ist dieselbe Richtlinie, die der Schutzgruppe zugewiesen ist.

. Wählen Sie die Zeitplanstufe aus.
. Wählen Sie *Sichern*.
