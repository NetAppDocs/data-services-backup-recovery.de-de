= Bekannte Einschränkungen für VMware Workloads in NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Diese Einschränkungen sollten vor der Verwendung von NetApp Backup and Recovery für VMware-Workloads geprüft werden.

NetApp Backup and Recovery unterstützt die folgenden Aktionen für VMware-Workloads nicht:

* In der Backup and Recovery-Vorabversion für die lokale Bereitstellung der NetApp Console werden Backups in Objektspeicher nur für ONTAP S3 und StorageGRID Ziele unterstützt. Backup-Archivierung ist in dieser Vorabversion nicht unterstützt.
* vVol-Unterstützung
* E-Mail-Integration
* Unterstützung der rollenbasierten Zugriffskontrolle (RBAC)
