= VMware-Schutzgruppen in NetApp Backup and Recovery verwalten
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Schutzgruppen dienen zur Verwaltung von Sicherungs- und Wiederherstellungsvorgängen für eine Gruppe von Workloads. Eine Schutzgruppe ist eine logische Gruppierung von Ressourcen wie VMs und Datastores, die gemeinsam geschützt werden sollen.

Sie können die folgenden Aufgaben im Zusammenhang mit Schutzgruppen ausführen:

* Erstellen Sie eine Schutzgruppe, indem Sie VMs manuell zur Gruppe hinzufügen oder VMware vSphere-Tags verwenden.
* Schutzdetails anzeigen.
* Sichern Sie jetzt eine Schutzgruppe. Siehe link:br-use-vmware-backup.html["Sichern Sie jetzt VMware-Workloads"].
* Unterbrechen und Fortsetzen des Sicherungszeitplans einer Schutzgruppe.
* Löschen Sie eine Schutzgruppe.




[[tag-based-protection-groups]]
== Tag-basierte Schutzgruppen

Bei der Auswahl von Ressourcen, die einer Schutzgruppe hinzugefügt werden sollen, können Sie diese nach Datenspeichern, virtuellen Maschinen oder nach vSphere Tags organisieren.

Tag-basierter Schutz mithilfe von vSphere Tags vereinfacht die Verwaltung von Schutzgruppen in NetApp Backup and Recovery.

Die Verwendung von tagbasiertem Schutz bietet einige Vorteile:

* Wenn Sie einem VM oder Datastore in vCenter ein vSphere-Tag hinzufügen, wird dieses Objekt automatisch in das nächste Backup für jede NetApp Backup and Recovery-Schutzgruppe aufgenommen, die auf dieses Tag verweist.
* Wenn Sie einen vSphere-Tag von einer VM oder einem Datenspeicher entfernen, wird dieses Objekt automatisch von nachfolgenden Backups für diese tagbasierte Schutzgruppe ausgeschlossen.
* Wenn ein vSphere-Tag in vCenter gelöscht wird, überspringen zukünftige Backups diesen Tag und melden eine Warnung.
* Wird eine VM in einen anderen Datenspeicher migriert, bleibt sie so lange geschützt, wie sie noch das Tag besitzt, das Teil einer tagbasierten Schutzgruppe ist.


Die Tag-Zugehörigkeit wird zum Zeitpunkt der Sicherung von vCenter aufgelöst. Alle Änderungen, die Sie an Tags in vCenter vornehmen (Hinzufügen/Entfernen von Tags, Löschen von Tags, Hinzufügen/Entfernen von VMs), werden automatisch in der nächsten Sicherung berücksichtigt.



[[create-a-protection-group]]
== Erstellen einer Schutzgruppe

Erstellen Sie eine Schutzgruppe, um die Ressourcen zu organisieren, die Sie gemeinsam sichern und wiederherstellen möchten.

*Erforderliche NetApp Console-Rolle* Backup and Recovery Superadmin- oder Backup and Recovery Backup-Admin-Rolle https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Erfahren Sie mehr über die Zugriffsrollen der NetApp Console für alle Dienste"^].

.Bevor Sie beginnen
* Ihre Umgebung sollte unterstützte Versionen von VMware vSphere verwenden.
* Beim Erstellen einer tagbasierten Schutzgruppe ist sicherzustellen, dass die virtuellen Maschinen und Datenspeicher, die geschützt werden sollen, bereits einem oder mehreren vSphere Tags in vCenter zugeordnet sind.
* Bei VMware-Workloads wird für die geplante Sicherungszeit die Zeitzone des Verwaltungshosts verwendet. Weitere Informationen sind unter link:br-use-policies-vmware-create.html["Erstellen und Verwalten von VMware-Sicherungsrichtlinien in NetApp Backup und Recovery"] zu finden.


.Schritte
. Wählen Sie im NetApp Backup and Recovery -Menü *Inventar* aus.
. Wählen Sie eine Arbeitslast aus, um die Schutzdetails anzuzeigen.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Details anzeigen*.
. Wählen Sie die Registerkarte *Schutzgruppen*.
. Wählen Sie *Schutzgruppe erstellen*.
. Geben Sie einen Namen für die Schutzgruppe an und wählen Sie aus, wie Sie Ressourcen zur Schutzgruppe hinzufügen möchten. Sie können Ressourcen nach *Datenspeichern*, *Virtuellen Maschinen* oder *Tags* hinzufügen.
+

IMPORTANT: Das Mischen von Ressourcentypen (z. B. das Kombinieren von Tags mit einzelnen VMs oder Datenspeichern in derselben Schutzgruppe) wird nicht unterstützt.

. Wählen Sie aus der angezeigten Liste die Ressourcen aus, die Sie in die Schutzgruppe aufnehmen möchten.
+
Sie können die verfügbaren Ressourcen in der Liste filtern, indem Sie ein bestimmtes vCenter oder Rechenzentrum auswählen. Die ausgewählten Ressourcen werden rechts in der Liste angezeigt.

. Wenn Sie fertig sind, wählen Sie *Weiter*.
. Wählen Sie aus, wie die Schutzgruppe mit VMs umgeht, deren virtuelle Festplatten sich über mehrere Datenspeicher erstrecken:
+
** *Grundsätzlicher Ausschluss aller übergreifenden Datastores*: Die Schutzgruppe umfasst nur Datastores, die ihr direkt hinzugefügt werden, sowie den primären Datastore aller VMs, die der Schutzgruppe direkt hinzugefügt werden.
** *Immer alle übergreifenden Datastores einbeziehen*: Die Schutzgruppe umfasst alle Datastores, die von den einbezogenen VMs überspannt werden.
** *Manuelle Auswahl der einzuschließenden übergreifenden Datenspeicher*: Wenn Sie diese Option auswählen, wählen Sie die übergreifenden Datenspeicher, die in die Schutzgruppe aufgenommen werden sollen, manuell aus der angezeigten Liste aus. Diese Auswahl ist statisch, daher ist bei jeder Hinzufügung neuer VMs zur Gruppe eine Aktualisierung der Liste der übergreifenden Datenspeicher erforderlich.


. Wählen Sie *Weiter*.
. Wählen Sie die Datensicherungsstrategie, die Sie auf die Schutzgruppe anwenden möchten.
+
Um eine neue Richtlinie zu erstellen, wählen Sie *Neue Richtlinie erstellen* und folgen Sie den Anweisungen. Weitere Informationen finden Sie unter link:br-use-policies-create.html["Erstellen von Richtlinien"].

. Wählen Sie *Weiter*.
. Überprüfen Sie die Konfiguration.
. Wählen Sie *Erstellen* aus, um die Schutzgruppe zu erstellen.




[[suspend-a-protection-groups-backup-schedule]]
== Aussetzen des Sicherungszeitplans einer Schutzgruppe

Setzen Sie eine Schutzgruppe aus, um ihre geplanten Sicherungen anzuhalten.

Wenn Sie eine Schutzgruppe aussetzen, ändert sich der Schutzstatus in „In Wartung“. Sie können den Sicherungszeitplan jederzeit fortsetzen.

.Schritte
. Wählen Sie im NetApp Backup and Recovery -Menü *Inventar* aus.
. Wählen Sie eine Arbeitslast aus, um die Schutzdetails anzuzeigen.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Details anzeigen*.
. Wählen Sie die Registerkarte *Schutzgruppen*.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Schutzgruppe aussetzen*.
. Überprüfen Sie die Bestätigungsnachricht und wählen Sie *Aussetzen*.




[[resume-a-protection-groups-backup-schedule]]
== Fortsetzen des Sicherungszeitplans einer Schutzgruppe

Durch die Wiederaufnahme einer angehaltenen Schutzgruppe werden die geplanten Sicherungen für die Schutzgruppe neu gestartet.

Der Schutzstatus ändert sich von „In Wartung“ zu „Geschützt“, wenn Sie eine Schutzgruppe fortsetzen. Sie können den Sicherungsplan jederzeit fortsetzen.

.Schritte
. Wählen Sie im NetApp Backup and Recovery -Menü *Inventar* aus.
. Wählen Sie eine Arbeitslast aus, um die Schutzdetails anzuzeigen.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Details anzeigen*.
. Wählen Sie die Registerkarte *Schutzgruppen*.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Schutzgruppe fortsetzen*.
. Überprüfen Sie die Bestätigungsnachricht und wählen Sie *Fortsetzen*.


.Ergebnis
Das System validiert die Zeitpläne und ändert den Schutzstatus auf „Geschützt“, wenn die Zeitpläne gültig sind. Wenn die Zeitpläne ungültig sind, zeigt das System eine Fehlermeldung an und nimmt die Schutzgruppe nicht wieder auf.



[[edit-a-protection-group]]
== Bearbeiten Sie eine Schutzgruppe

Bearbeiten Sie eine Schutzgruppe, um deren Namen oder Einstellungen zu ändern. Möglicherweise möchten Sie eine Schutzgruppe bearbeiten, wenn sich die Ressourcen in der Gruppe geändert haben.

.Schritte
. Wählen Sie im NetApp Backup and Recovery -Menü *Inventar* aus.
. Wählen Sie eine Arbeitslast aus, um die Schutzdetails anzuzeigen.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Details anzeigen*.
. Wählen Sie die Registerkarte *Schutzgruppen*.
. Wählen Sie die Schutzgruppe aus, die Sie bearbeiten möchten.
. Wählen Sie das Symbol „Aktionen“ aus. image:../media/icon-action.png["Aktionsoption"] > *Bearbeiten*.
+
Der Assistent zum Bearbeiten der Schutzgruppe führt Sie durch die Einstellungen in der Schutzgruppe.

. Auf jedem Bildschirm des Assistenten sind die erforderlichen Änderungen vorzunehmen.
. Nach Abschluss *Absenden* auswählen.




[[apply-an-updated-vcenter-time-zone-to-an-existing-protection-group]]
=== Eine aktualisierte vCenter-Zeitzone auf eine bestehende Schutzgruppe anwenden

Geplante Backups verwenden die vCenter Server-Zeitzone, die beim Erstellen des Zeitplans der Schutzgruppe festgelegt wird. Wenn die vCenter Server-Zeitzone geändert wird, laufen bestehende Schutzgruppen weiterhin in ihrer ursprünglichen Zeitzone (typischerweise UTC), bis deren Zeitpläne aktualisiert werden.


NOTE: Zeitpläne werden nur neu erstellt, wenn Sie den Namen der Schutzgruppe ändern, eine VM hinzufügen oder entfernen, die zugewiesene Richtlinie ändern oder Pre-/Post-Skripte aktualisieren. Das Speichern ohne Änderungen aktualisiert die Zeitpläne nicht. Diese Aktualisierung des Zeitplans ist eine einmalige Aktion pro Schutzgruppe und startet keine sofortige Sicherung.

.Schritte
. Aktualisieren Sie den vCenter Server, damit seine aktuelle Zeitzone abgerufen wird.
. Die Schutzgruppe kann bearbeitet und ihr Name auf einen anderen Wert geändert werden, anschließend wird gespeichert.




[[delete-a-protection-group]]
== Löschen einer Schutzgruppe

Wenn Sie eine Schutzgruppe löschen, werden diese und alle Sicherungspläne für die Gruppe entfernt. Eine Schutzgruppe kann gelöscht werden, wenn sie nicht mehr benötigt wird.

.Schritte
. Wählen Sie im NetApp Backup and Recovery -Menü *Inventar* aus.
. Wählen Sie eine Arbeitslast aus, um die Schutzdetails anzuzeigen.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Details anzeigen*.
. Wählen Sie die Registerkarte *Schutzgruppen*.
. Wählen Sie die Schutzgruppe aus, die Sie löschen möchten.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Löschen*.
. Überprüfen Sie die Bestätigungsmeldung zum Löschen der zugehörigen Sicherungen und bestätigen Sie den Löschvorgang.
