= Kubernetes-Schutzberichte in NetApp Backup and Recovery verwalten
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
In NetApp Backup und Recovery Kubernetes-Schutzberichte erstellen, um den Sicherungsstatus, die Sicherungstypen und den Clusterzustand zu überwachen.

*Erforderliche NetApp Console-Rolle* Backup and Recovery Superadmin, Backup and Recovery Backup-Admin oder Backup and Recovery Restore-Admin. Für den Schutz von Daten, die auf einem Cloud Volumes ONTAP Cluster gespeichert sind, ist zusätzlich die Cloud Volumes ONTAP Admin-Rolle erforderlich. Informationen zu link:reference-roles.html["Rollen und Berechtigungen für Backup und Wiederherstellung"]. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Erfahren Sie mehr über die Zugriffsrollen der NetApp Console für alle Dienste"^].



[[create-a-protection-report]]
== Erstellen Sie einen Schutzbericht

Ein Schutzbericht zeigt den Schutzstatus Ihrer Cluster an.

.Schritte
. Im NetApp Backup und Recovery-Menü die Option *Berichte* auswählen.
. Wählen Sie *Bericht erstellen*.
. Geben Sie Details zum Berichtsumfang ein:
+
** *Berichtsname*: Geben Sie einen eindeutigen Namen für den Bericht ein.
** *Berichtstyp*: Wählen Sie, ob Sie einen Bericht nach Konto oder nach Workload wünschen (wählen Sie Kubernetes aus der Liste).
** *Cluster auswählen*: Wenn Sie die Auswahl anhand der Arbeitslast getroffen haben, wählen Sie den Cluster aus der Liste aus, für den Sie den Bericht generieren möchten, und wählen Sie *Akzeptieren*. Wählen Sie *Alle auswählen*, um einen Bericht für alle Cluster zu generieren.


. Berichtszeitraum eingeben: Wählen Sie, ob der Bericht Daten vom letzten Tag, den letzten 7 Tagen, den letzten 30 Tagen, dem letzten Quartal oder dem letzten Jahr enthalten soll.
. Geben Sie die Konfigurationsdetails für den Bericht ein: Es kann ausgewählt werden, ob der Bericht einmalig oder nach einem wiederkehrenden Zeitplan ausgeführt wird. Bei geplanten Berichten kann die Häufigkeit der Wiederholung sowie ein Startdatum ausgewählt werden.
+
.. E-Mail-Zustellungsdetails eingeben: Nur für geplante Berichte eine oder mehrere E-Mail-Adressen angeben, an die der Bericht gesendet wird.


+
E-Mail-Benachrichtigungen werden auf der Seite *Einstellungen* konfiguriert. Einzelheiten zur Konfiguration von E-Mail-Benachrichtigungen finden sich unter link:br-start-configure.html["Konfigurieren der Einstellungen"].

. Wählen Sie *Erstellen*.




[[download-a-protection-report]]
== Laden Sie einen Schutzbericht herunter

Laden Sie einen generierten Schutzbericht entweder als JSON-Datei oder als PDF-Dokument herunter, damit Sie ihn anzeigen und weitergeben können.

.Schritte
. Im NetApp Backup und Recovery-Menü die Option *Berichte* auswählen.
. Auf der Seite *Berichte* wählen Sie das Menü *Berichte* aus, um die Liste der generierten Schutzberichte anzuzeigen.
. Für den Bericht, den Sie herunterladen möchten, wählen Sie das Aktionen-Symbol image:../media/icon-action.png["Aktionsoption"] > *Download*.
+
** Wählen Sie *Download JSON*, um den Bericht im JSON-Format herunterzuladen.
** Wählen Sie *Download PDF*, um den Bericht als PDF-Dokument herunterzuladen.






[[view-a-protection-report]]
== Einen Schutzbericht anzeigen

Interaktive Details eines Schutzberichts innerhalb von NetApp Backup und Recovery anzeigen. Es werden Zusammenfassungsinformationen zum Auftrag, der Status des Datenschutzes, Konfigurationsdetails und weitere Informationen angezeigt.

.Schritte
. Im NetApp Backup und Recovery-Menü die Option *Berichte* auswählen.
. Auf der Seite *Berichte* wählen Sie das Menü *Berichte* aus, um die Liste der generierten Schutzberichte anzuzeigen.
. Für den Bericht, den Sie anzeigen möchten, wählen Sie das Aktionen-Symbol image:../media/icon-action.png["Aktionsoption"] > *Bericht anzeigen*.
+
Die Berichtsdetails werden angezeigt.





[[delete-a-protection-report]]
== Einen Schutzbericht löschen

Löschen Sie einen Datensicherungsbericht, wenn Sie ihn nicht mehr benötigen.

.Schritte
. Im NetApp Backup und Recovery-Menü die Option *Berichte* auswählen.
. Auf der Seite *Berichte* wählen Sie das Menü *Berichte* aus, um die Liste der generierten Schutzberichte anzuzeigen.
. Für den Bericht, den Sie löschen möchten, wählen Sie das Aktionen-Symbol image:../media/icon-action.png["Aktionsoption"] > *Löschen*.
. Bestätigen Sie die Aktion, indem Sie *Löschen* auswählen.
