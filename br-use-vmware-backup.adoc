= Sichern Sie VMware-Workloads mit NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
VMware-VMs und Datenspeicher können von lokalen ONTAP-Systemen zu Amazon Web Services, Azure NetApp Files oder StorageGRID gesichert werden, um den Schutz Ihrer Daten zu unterstützen. Backups werden automatisch erstellt und in einem Objektspeicher in Ihrem öffentlichen oder privaten Cloud-Konto gespeichert.

* Um Workloads regelmäßig zu sichern, erstellen Sie Richtlinien, die die Sicherungs- und Wiederherstellungsvorgänge steuern. Siehe link:br-use-policies-create.html["Schutzrichtlinien erstellen"] für Anweisungen.
* Erstellen Sie Schutzgruppen, um die Backup- und Recovery-Vorgänge für eine Gruppe von Ressourcen zu verwalten. Siehe link:br-use-vmware-protection-groups.html["Schutzgruppen erstellen und verwalten"] für weitere Informationen.
* Workloads können jetzt durch Erstellen eines On-Demand-Backups gesichert werden.




[[back-up-workloads-now-with-an-on-demand-backup]]
== Sichern Sie Workloads jetzt mit einem On-Demand-Backup

Erstellen Sie sofort ein On-Demand-Backup.  Möglicherweise möchten Sie eine On-Demand-Sicherung ausführen, wenn Sie Änderungen an Ihrem System vornehmen und sicherstellen möchten, dass Sie vor dem Start über eine Sicherung verfügen.

*Erforderliche NetApp Console-Rolle*: Backup and Recovery Super Admin, Backup and Recovery Backup Admin, Backup and Recovery Clone Admin oder Backup and Recovery Viewer Rolle. Für den Schutz von Daten, die auf einem Cloud Volumes ONTAP Cluster gespeichert sind, ist zusätzlich die Cloud Volumes ONTAP Admin-Rolle erforderlich https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Erfahren Sie mehr über die Zugriffsrollen der NetApp Console für alle Dienste"^].

.Schritte
. Wählen Sie im NetApp Backup and Recovery -Menü *Inventar* aus.
. Die VMware Workload auswählen.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Details anzeigen*.
. Wählen Sie die Menüüberschrift *Protection Groups*, *Datastores*, *Virtual machines* oder *Tags* aus.
. Wählen Sie die Schutzgruppe, Datenspeicher, virtuellen Maschinen oder getaggten Ressourcen aus, die Sie sichern möchten.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Jetzt sichern*.
+

NOTE: Die für die Datensicherung angewendete Richtlinie ist dieselbe Richtlinie, die der Schutzgruppe, dem Datenspeicher, der virtuellen Maschine oder den getaggten Ressourcen zugewiesen ist.

. Wählen Sie die Zeitplanstufe aus.
. Wählen Sie *Jetzt sichern*.




[[delete-backups]]
== Backups löschen

Sie können lokale Backups löschen, die nicht mehr benötigt werden, um Speicherplatz freizugeben oder Datenaufbewahrungsvorschriften zu erfüllen.

.Schritte
. Melden Sie sich bei NetApp Backup and Recovery an und wählen Sie auf dem Startbildschirm die VMware Workload-Kachel aus.
+
Die VMware Inventarseite wird angezeigt.

. Die Überschrift *Virtuelle Maschinen* auswählen.
. In der Liste der virtuellen Maschinen eine virtuelle Maschine auswählen und das Aktionen-Symbol image:../media/icon-action.png["Aktionsoption"] > *Schutzdetails anzeigen* wählen.
. Einen Zeitraum auswählen, um relevante Momentaufnahmen anzuzeigen.
. Ein oder mehrere Snapshots löschen:
+
[role="tabbed-block"]
====
.Einen einzelnen Snapshot löschen
--
.. Wählen Sie aus der Liste den Snapshot aus, den Sie löschen möchten, und wählen Sie das Symbol Aktionen image:../media/icon-action.png["Aktionsoption"] > *Lokalen Snapshot löschen*.


--
.Mehrere Snapshots löschen
--
.. Aktivieren Sie das Kästchen links neben jedem Snapshot, den Sie löschen möchten.
.. *Ausgewählte löschen* auswählen.


--
====
