NetApp Backup and Recovery unterstützt die Google Cloud Storage Archivstufe für ältere Backups. Informationen zu den Wiederherstellungskosten und Abrufzeiten für Backups in dieser Stufe sind verfügbar.



[[supported-google-archival-storage-classes-for-netapp-backup-and-recovery]]
== Unterstützte Google-Archivspeicherklassen für NetApp Backup and Recovery

Wenn Backup-Dateien initial erstellt werden, werden sie im _Standard_-Speicher gespeichert. Diese Speicherebene ist für die Speicherung von Daten optimiert, auf die selten zugegriffen wird, ermöglicht aber dennoch sofortigen Zugriff.

Wenn Ihr lokaler Cluster ONTAP 9.12.1 oder höher verwendet, können Sie ältere Backups nach einer bestimmten Anzahl von Tagen (in der Regel mehr als 30 Tage) in der NetApp Backup and Recovery Benutzeroberfläche zur weiteren Kostenoptimierung in den _Archive_ Storage verschieben. Für Daten in dieser Ebene fallen höhere Kosten bei der Wiederherstellung an. Daher sollte berücksichtigt werden, wie häufig Daten aus diesen archivierten Backup-Dateien wiederhergestellt werden müssen. Auf dieser Seite gibt es einen Abschnitt zum Wiederherstellen von Daten aus Archivierungs-Storage.

Wenn Sie NetApp Backup and Recovery mit dieser Art von Lebenszyklusregel konfigurieren, sollten Sie beim Einrichten des Buckets in Ihrem Google-Konto keine Lebenszyklusregeln konfigurieren.

https://cloud.google.com/storage/docs/storage-classes["Informationen zu Google-Speicherklassen"^].



[[restore-data-from-archival-storage]]
== Daten aus dem Archivspeicher wiederherstellen

Die Speicherung älterer Sicherungsdateien in Archive Storage ist deutlich günstiger als in Standard Storage. Die Wiederherstellung von Daten aus einer Sicherungsdatei in Archive Storage dauert jedoch etwas länger und ist teurer.

Wie viel kostet die Wiederherstellung von Daten aus dem Google-Archiv?:: Detaillierte Preise für Google Cloud Storage nach Regionen finden Sie auf der https://cloud.google.com/storage/pricing["Preisseite für Google Cloud Storage"^] .
Wie lange dauert die Wiederherstellung meiner im Google-Archiv archivierten Objekte?:: Die gesamte Wiederherstellungszeit setzt sich aus zwei Teilen zusammen:
+
--
* *Abrufzeit*: Die Zeit, die zum Abrufen der Sicherungsdatei aus dem Archiv und zum Platzieren im Standardspeicher benötigt wird.  Dies wird manchmal als „Rehydratationszeit“ bezeichnet.  Im Gegensatz zu den „kältesten“ Speicherlösungen anderer Cloud-Anbieter sind Ihre Daten innerhalb von Millisekunden zugänglich.
* *Wiederherstellungszeit*: Die Zeit, die benötigt wird, um die Daten aus der Sicherungsdatei in Standard Storage wiederherzustellen. Diese Zeit entspricht der für eine typische Wiederherstellung direkt aus Standard Storage, wenn keine Archivierungsebene verwendet wird.


--


[NOTE]
====
Das Wiederherstellen eines Volumes oder einer Datei aus dem Archivspeicher kann zusätzliche Zeit in Anspruch nehmen. Der Auftrag bleibt im *Job Monitor* als *In progress* angezeigt, während Backup and Recovery die Wiederherstellung entsprechend der ausgewählten Priorität erneut versucht. Die Wiederherstellung kann im *Job Monitor* überwacht werden; sie ist abgeschlossen, wenn der Auftrag nach allen Wiederholungsversuchen einen endgültigen Status wie *Completed* oder *Failed* erreicht. Eine weitere Wiederherstellung sollte nur gestartet werden, wenn der Auftrag letztlich fehlschlägt.
