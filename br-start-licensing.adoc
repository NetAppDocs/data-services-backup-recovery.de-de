= Einrichten der Lizenzierung für NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Die Lizenzierung für NetApp Backup and Recovery in NetApp Console oder im lokalen Deployment von NetApp Console erfolgt mithilfe eines Marketplace-Abonnements oder einer Bring-your-own-Lizenz (BYOL) von NetApp. Eine gültige Lizenz ist erforderlich, um Workloads in Objektspeicher zu schützen und Daten aus Objektspeicher wiederherzustellen. Lokale Snapshots und die Replikation auf sekundären ONTAP Storage erfordern keine Lizenz.

Ein paar Anmerkungen zur Funktionsweise von Lizenzen:

* Für alle Workloads fallen nur Gebühren für den Schutz in Object Storage an (z. B. bei Verwendung der 3-2-1-Backup-Architekturen oder von Disk zu Object Storage). Lokale Snapshots und die Replikation auf ONTAP Secondary Storage sind kostenlos.
* Für Oracle Database Workloads ist keine Lizenz erforderlich, da sie sich im Preview-Status befinden.
* Bei der Verwendung von ONTAP Volumes Workloads können Sie Volumes ohne Lizenz identifizieren und wiederherstellen. Wenn Sie Volumes jedoch zum Schutz (zur Sicherung) in Objekt-Storage benötigen, müssen Sie eine Lizenz erwerben.
* Wenn Sie Backup and Recovery mit NetApp Console lokaler Bereitstellung verwenden, kann ausschließlich eine Bring-Your-Own-License-(BYOL)-Lizenz erworben werden.
* Die Bring-Your-Own-License (BYOL) von NetApp Backup and Recovery ist eine Floating-Lizenz, die Sie auf allen Systemen verwenden können, die mit Ihrer NetApp Console -Organisation oder Ihrem NetApp Console-Konto verknüpft sind.  Wenn Ihnen also durch eine vorhandene BYOL-Lizenz ausreichend Sicherungskapazität zur Verfügung steht, müssen Sie keine weitere BYOL-Lizenz erwerben.
* Wenn eine BYOL-Lizenz mit NetApp Console verwendet wird, wird zusätzlich ein PAYGO-Abonnement empfohlen. Wenn mehr Daten gesichert werden, als durch die BYOL-Lizenz erlaubt ist, oder wenn die Laufzeit der Lizenz abläuft, wird die Sicherung über das Pay-as-you-go (PAYGO) Abonnement fortgesetzt, ohne dass es zu einer Unterbrechung des Service kommt.
* Beim Sichern von On-Premises ONTAP Daten in StorageGRID wird eine BYOL-Lizenz benötigt, für den Speicherplatz des Cloud-Anbieters fallen jedoch keine Kosten an.


link:concept-backup-to-cloud.html["Erfahren Sie mehr über die Kosten im Zusammenhang mit der Verwendung von NetApp Backup and Recovery."]



[[licensing-options-for-netapp-backup-and-recovery]]
== Lizenzierungsoptionen für NetApp Backup und Recovery

Es gibt drei Lizenzierungsoptionen für NetApp Backup and Recovery:

* Eine Direktlizenz, auch bekannt als Bring-Your-Own-License (BYOL), kann von NetApp erworben werden. Diese Option gilt sowohl für die NetApp Console als auch für die lokale Console-Bereitstellung.
* Ein Jahresvertrag kann über einen Hyperscaler Marketplace erworben werden. Diese Option gilt nur für die NetApp Console.
* Ein Abonnement für eine Pay-as-you-go-Lizenz (PAYGO) aus einem Hyperscaler-Marktplatz ist möglich. Diese Option gilt nur für die NetApp Console.




[[30-day-free-trial]]
=== 30 Tage kostenlos testen

Für alle nicht lizenzierten Workloads außer ONTAP Volumes Workloads ist eine 30-tägige kostenlose Testversion von NetApp Backup and Recovery verfügbar. Die Testversion kann beim Beginn der Nutzung eines Workloads gestartet werden, noch bevor dessen Ressourcen identifiziert werden. Nach dem Start der Testversion werden ihr Status und die genutzte Kapazität auf der Startseite von NetApp Backup and Recovery unter *Free Trials* angezeigt. Nur die in Objektspeicher geschützte Kapazität wird auf die Testversion angerechnet. Kapazität, die durch lokale Snapshots oder Replikation auf ONTAP Secondary Storage geschützt ist, wird nicht angerechnet.



==== Kostenlose Testversion beenden

Sie können die kostenlose Testphase für eine Workload jederzeit auf der Startseite beenden, die angezeigt wird, wenn Sie sich bei NetApp Backup and Recovery anmelden. Wenn Sie Workloads nach Ablauf der kostenlosen Testphase weiterhin in Objektspeicher schützen möchten, müssen Sie im Abschnitt *Licenses and subscriptions* der Benutzeroberfläche von NetApp Console ein kostenpflichtiges Abonnement einrichten. Schutz, bei dem kein Objektspeicher verwendet wird, z. B. lokale Snapshots und die Replikation auf sekundären ONTAP Storage, funktioniert weiterhin und kann ohne kostenpflichtiges Abonnement gemanagt werden. Wenn Sie Workloads nicht weiterhin in Objektspeicher schützen möchten, können Sie die kostenlose Testphase beenden, ohne ein kostenpflichtiges Abonnement abzuschließen. Sie können link:prev-ontap-backup-manage.html["Aufheben der Registrierung von NetApp Backup and Recovery vom System"] vor Ablauf der Testphase und es fallen keine Gebühren an.

.Schritte
. Auf der Startseite von NetApp Backup and Recovery unter *Kostenlose Testversionen* die gewünschte Testversion auswählen, die beendet werden soll.
. Wählen Sie *Kostenlose Testversion beenden*.
. Geben Sie *Testversion beenden* in das Feld ein.
. *Testversion beenden* auswählen, um zu bestätigen.




[[use-a-byol-license]]
=== Eine BYOL-Lizenz verwenden

Bring-your-own-Lizenzen von NetApp haben Laufzeiten von 1, 2 oder 3 Jahren. Sie zahlen nur für die Daten, die Sie in Object Storage schützen, berechnet anhand der genutzten logischen Kapazität (_vor_ jeglichen Effizienzsteigerungen) der Quell-Workloads, die in Object Storage gesichert werden. Bei ONTAP Volumes wird diese Kapazität auch als Front-End Terabytes (FETB) bezeichnet. Daten, die nur durch lokale Snapshots oder Replikation auf sekundären ONTAP Storage geschützt sind, werden nicht auf Ihre lizenzierte Kapazität angerechnet.

Die BYOL-Lizenz für NetApp Backup and Recovery ist eine Floating-Lizenz, deren Gesamtkapazität von allen Systemen gemeinsam genutzt wird, die Ihrem NetApp Console Unternehmen oder Konto zugeordnet sind. Für ONTAP Volumes lässt sich der benötigte Speicherplatz grob abschätzen, indem der CLI-Befehl `volume show -fields logical-used-by-afs` für die Volumes ausgeführt wird, die im Objektspeicher gesichert werden sollen.

Falls Sie keine BYOL-Lizenz für NetApp Backup and Recovery besitzen, können Sie sich an Ihren NetApp Vertriebsmitarbeiter wenden, um eine solche zu erwerben.

Sie verwenden die NetApp Console oder die NetApp Console lokale Bereitstellung, um BYOL-Lizenzen zu verwalten. Neue Lizenzen können hinzugefügt, bestehende Lizenzen aktualisiert und der Lizenzstatus in der Console angezeigt werden.

https://docs.netapp.com/us-en/console-licenses-subscriptions/task-manage-data-services-licenses.html["Informationen zum Hinzufügen von Lizenzen"^].



[[use-an-annual-marketplace-subscription-applies-to-netapp-console-only]]
=== Verwendung eines jährlichen Marketplace-Abonnements (gilt nur für NetApp Console)

Sie können für NetApp Backup and Recovery jährlich bezahlen, indem Sie einen Jahresvertrag mit mehreren Laufzeitoptionen abschließen.

Bei einem Jahresvertrag über einen Marktplatz wird der gesamte Verbrauch von NetApp Backup and Recovery für den Schutz in Object Storage über diesen Vertrag abgerechnet.

Zu den jährlichen Marktplatzvertragsoptionen gilt Folgendes:

* Jahresverträge sind in jedem Marketplace als private Angebote verfügbar.
* Mit Jahresverträgen können Sie sowohl Cloud Volumes ONTAP Daten als auch lokale ONTAP Daten sichern.
* Sie können sich auf der Marketplace-Seite für einen Jahresvertrag anmelden. Sie können Ihr Abonnement auf der Marketplace-Seite einrichten und es anschließend mit Ihren  https://docs.netapp.com/us-en/console-setup-admin/task-adding-aws-accounts.html["AWS"^], https://docs.netapp.com/us-en/console-setup-admin/task-adding-azure-accounts.html#subscribe["Azure"^] oder GCP-Anmeldeinformationen verknüpfen. Außerdem müssen Sie Ihre Cloud Volumes ONTAP Systeme über dieses Jahresvertragsabonnement bezahlen, da Sie Ihren AWS-Anmeldeinformationen in der Console nur ein aktives Abonnement zuweisen können.
* Beim Kauf eines „CVO Professional“-Plans sind unbegrenzte Backups für das lizenzierte Cloud Volumes ONTAP-System enthalten. Diese Backups werden nicht auf die lizenzierte Kapazität angerechnet. Dieser Plan unterstützt keine Backups von On-Premises-ONTAP-Daten oder Cloud Volumes ONTAP-Systemen, die über die Freemium- oder Essentials-Pakete lizenziert wurden; unterstützt werden nur Cloud Volumes ONTAP-Systeme, die über das Professional-Paket lizenziert wurden.
+
Weitere Informationen zu dieser Lizenzierungsoption finden sich in der https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/concept-licensing.html["Thema zur Lizenzierung von Cloud Volumes ONTAP"^].



Bei der Verwendung von AWS oder Azure sind über diese Links jährliche Marketplace-Abonnements für NetApp Backup and Recovery verfügbar:

* AWS: https://aws.amazon.com/marketplace/pp/prodview-q7dg6zwszplri["Preisdetails finden Sie im Marketplace-Angebot für NetApp Intelligent Services."^].

Wenn Sie GCP nutzen, können Sie einen Jahresvertrag über Ihren NetApp Vertriebsmitarbeiter erwerben.

=== Ein NetApp Backup and Recovery PAYGO-Abonnement verwenden (gilt nur für die NetApp Console)

Bei der nutzungsbasierten Abrechnung zahlen Sie Ihrem Cloud-Anbieter die Kosten für Objektspeicherung und NetApp Backup-Lizenzierung stundenweise in einem einzigen Abonnement. Ein Abonnement für *NetApp Intelligent Services* im Marketplace wird auch bei Nutzung einer kostenlosen Testversion oder einer eigenen Lizenz (BYOL) empfohlen.

* Mit einem Abonnement ist sichergestellt, dass der Service nach Ablauf der kostenlosen Testphase ohne Unterbrechung weiterläuft. Nach Ablauf der Testphase werden Ihnen die Kosten stündlich entsprechend der Datenmenge berechnet, die Sie in Objektspeicher sichern.
* Wenn Sie mehr Daten sichern, als Ihre BYOL-Lizenz zulässt, werden die Datensicherungs- und Wiederherstellungsvorgänge über Ihr Pay-as-you-go-Abonnement fortgesetzt.  Wenn Sie beispielsweise über eine BYOL-Lizenz mit 10 TiB verfügen, wird die gesamte Kapazität über 10 TiB hinaus über das PAYGO-Abonnement abgerechnet.


Während Ihrer kostenlosen Testphase oder wenn Sie Ihre BYOL-Lizenz nicht überschritten haben, werden Ihnen keine Kosten für Ihr Pay-as-you-go-Abonnement in Rechnung gestellt.

https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/concept-licensing.html#capacity-based-licensing["Erfahren Sie mehr über diese kapazitätsbasierten Lizenzpakete"].

Zu den Vertragsoptionen des PAYGO Marketplace ist Folgendes zu beachten:

* Mit PAYGO-Verträgen lassen sich sowohl Daten aus Cloud Volumes ONTAP als auch lokale ONTAP Daten sichern.
* Sie können sich auf der Marketplace-Seite für einen PAYGO-Vertrag anmelden. Sie richten Ihr Abonnement auf der Marketplace-Seite ein und ordnen es anschließend Ihren https://docs.netapp.com/us-en/console-setup-admin/task-adding-aws-accounts.html["AWS"^], https://docs.netapp.com/us-en/console-setup-admin/task-adding-azure-accounts.html#subscribe["Azure"^] oder GCP-Anmeldedaten zu.
* Beim Kauf eines „CVO Professional“-Plans sind unbegrenzte Backups für das lizenzierte Cloud Volumes ONTAP-System enthalten. Diese Backups werden nicht auf die lizenzierte Kapazität angerechnet. Dieser Plan unterstützt keine Backups von On-Premises-ONTAP-Daten oder Cloud Volumes ONTAP-Systemen, die über die Freemium- oder Essentials-Pakete lizenziert wurden; unterstützt werden nur Cloud Volumes ONTAP-Systeme, die über das Professional-Paket lizenziert wurden.
+
Weitere Informationen zu dieser Lizenzierungsoption finden sich in der https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/concept-licensing.html["Thema zur Lizenzierung von Cloud Volumes ONTAP"^].

[[exceeding-license-capacity]]
== Überschreitung der Lizenzkapazität

Das Überschreiten Ihrer lizenzierten Kapazität für den Schutz auf Objekt-Storage löst PAYGO-Tarife aus. Ohne PAYGO-Abonnement können keine neuen Backups auf Objekt-Storage erstellt werden, bestehende Backups lassen sich jedoch weiterhin ohne Servicegarantie wiederherstellen. Lokale Snapshots und die Replikation auf ONTAP Sekundär-Storage sind davon nicht betroffen. Die Lizenz sollte vor ihrem Ablauf erneuert werden, da eine abgelaufene Lizenz neue Backups auf Objekt-Storage verhindert und den Service beeinträchtigt.



[[what-happens-when-your-license-expires]]
== Was passiert, wenn Ihre Lizenz abläuft

Wenn Ihre Backup and Recovery Lizenz abläuft:

* Backups aus bestehenden Backup-Richtlinien und Wiederherstellungen funktionieren weiterhin.
* Das Erstellen neuer Backup-Richtlinien zum Schutz in Objektspeicher oder die Ausweitung des Objektspeicherschutzes auf zusätzliche Workloads und Datastores ist nicht möglich.
* Sie können weiterhin Richtlinien erstellen und managen, die keinen Objektspeicher verwenden, wie z. B. Richtlinien für lokale Snapshots und die Replikation auf ONTAP Sekundär-Storage.
* Neue Backup and Recovery Funktionen und Verbesserungen stehen nicht zur Verfügung.
* NetApp technischer Support für Backup und Recovery ist nicht mehr verfügbar.


Lizenzverlängerung für:

* Erstellen und Ändern von Backup-Richtlinien für den Schutz in Objekt-Storage, einschließlich Richtlinien für applikationskonsistente Backups von Datenbanken, VMs und Kubernetes-Workloads.
* Neue Backup and Recovery Funktionen und Verbesserungen stehen zur Verfügung.
* Sie erhalten weiterhin NetApp technischen Support.
