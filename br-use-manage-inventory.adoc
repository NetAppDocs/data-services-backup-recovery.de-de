= Verwalten Sie den Microsoft SQL Server-Bestand mit NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Microsoft SQL Server Hosts, Instanzen und Datenbanken anzeigen und verwalten sowie deren Schutzeinstellungen ändern oder entfernen.

Zur Verwaltung Ihres Lagerbestands sind folgende Optionen verfügbar:

* Hostinformationen verwalten
+
** Zeitpläne aussetzen
** Hosts bearbeiten oder löschen


* Instanzinformationen verwalten
+
** Anmeldeinformationen einer Ressource zuordnen
** Sichern Sie jetzt, indem Sie ein On-Demand-Backup starten
** Schutzeinstellungen bearbeiten


* Verwalten von Datenbankinformationen
+
** Schützen Sie Datenbanken
** Datenbanken wiederherstellen
** Schutzeinstellungen bearbeiten
** Sichern Sie jetzt, indem Sie ein On-Demand-Backup starten


* Das Protokollverzeichnis wird unter *Inventory* > *Hosts* konfiguriert, bevor Datenbank-Hostprotokolle in Snapshots gesichert werden. Weitere Informationen finden sich unter link:br-start-setup.html["Konfigurieren der NetApp Backup and Recovery -Einstellungen"].




[[manage-host-information]]
== Hostinformationen verwalten

Hostinformationen verwalten, um sicherzustellen, dass die richtigen Hosts geschützt sind. Hostinformationen können bei Bedarf angezeigt, bearbeitet und gelöscht werden.

*Erforderliche NetApp Console-Rolle* Storage Viewer, Backup and Recovery Super Admin, Backup and Recovery Backup Admin, Backup and Recovery Restore Admin oder Backup and Recovery Clone Admin Rolle. Für den Schutz von Daten, die auf einem Cloud Volumes ONTAP Cluster gespeichert sind, ist zusätzlich die Cloud Volumes ONTAP Admin-Rolle erforderlich. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Erfahren Sie mehr über die Zugriffsrollen der NetApp Console für alle Dienste"^].

* Protokollverzeichnis konfigurieren. Weitere Informationen unter link:br-start-setup.html["Konfigurieren der NetApp Backup and Recovery -Einstellungen"].
* Zeitpläne aussetzen
* Einen Host bearbeiten
* Löschen eines Hosts




[[manage-hosts]]
=== Hosts verwalten

Sie können die in Ihrem System erkannten Hosts einzeln oder als Gruppe verwalten.


TIP: Um einen Host zu verwalten, ist in der Spalte „Hosts“ auf den Status „Nicht verwaltet“ zu achten. NetApp Backup and Recovery verwaltet bereits Hosts mit dem Status „Verwaltet“.

Nachdem Sie die Hosts in NetApp Backup and Recovery verwaltet haben, verwaltet SnapCenter die Ressourcen auf diesen Hosts nicht mehr.

*Erforderliche NetApp Console-Rolle* Storage Viewer oder Backup and Recovery Super Admin. Wenn Daten geschützt werden, die auf einem Cloud Volumes ONTAP Cluster gespeichert sind, ist zusätzlich die Cloud Volumes ONTAP Admin-Rolle erforderlich. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Erfahren Sie mehr über die Zugriffsrollen der NetApp Console für alle Dienste"^].

.Schritte
. Wählen Sie im Menü *Inventar* aus.
. Wählen Sie eine Arbeitslast aus, um die Schutzdetails anzuzeigen.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Details anzeigen*.
. Wählen Sie die Registerkarte *Hosts*.
. Wählen Sie einen oder mehrere Hosts aus. Wenn Sie mehrere Hosts auswählen, wird die Option *Massenaktionen* angezeigt. Wählen Sie *Verwalten (bis zu 5 Hosts)*.
. Wählen Sie das Symbol Aktionenimage:../media/icon-action.png["Aktionsoption"] > *Verwalten*.
. Überprüfen Sie die Hostabhängigkeiten:
+
** Wenn das vCenter nicht angezeigt wird, wählen Sie das Stiftsymbol aus, um die vCenter-Details hinzuzufügen oder zu bearbeiten.
** Wenn Sie ein vCenter hinzufügen, müssen Sie das vCenter auch registrieren, indem Sie *vCenter registrieren* auswählen.


. Wählen Sie *Einstellungen validieren*, um Ihre Einstellungen zu testen.
. Wählen Sie *Verwalten*, um den Host zu verwalten.




[[suspend-schedules]]
=== Zeitpläne aussetzen

Unterbrechen Sie Zeitpläne, um Sicherungs- und Wiederherstellungsvorgänge während der Hostwartung zu stoppen.

.Schritte
. Wählen Sie im NetApp Backup and Recovery -Menü *Inventar* aus.
. Wählen Sie den Host aus, auf dem Sie Zeitpläne aussetzen möchten.
. Wählen Sie die *Aktionen*image:icon-action.png["Symbol „Aktionen“"] Symbol und wählen Sie *Zeitpläne aussetzen*.
. Wählen Sie im Bestätigungsdialogfeld *Suspend* aus.




[[edit-a-host]]
=== Einen Host bearbeiten

Sie können die vCenter Serverinformationen, die Anmeldeinformationen für die Hostregistrierung und die erweiterten Einstellungen ändern.

.Schritte
. Wählen Sie im NetApp Backup and Recovery -Menü *Inventar* aus.
. Wählen Sie den Host aus, den Sie bearbeiten möchten.
. Wählen Sie die *Aktionen*image:icon-action.png["Symbol „Aktionen“"] Symbol und wählen Sie *Host bearbeiten*.
. Bearbeiten Sie die Hostinformationen.
. Wählen Sie *Fertig*.




[[delete-a-host]]

. Wählen Sie den Host aus, den Sie löschen möchten.
. Wählen Sie die *Aktionen*image:icon-action.png["Symbol „Aktionen“"] Symbol und wählen Sie *Host löschen*.
. Überprüfen Sie die Bestätigungsinformationen und wählen Sie *Löschen*.

* Trennen der Anmeldeinformationen
* Schutzeinstellungen bearbeiten

*Erforderliche NetApp Console-Rolle* Storage Viewer, Backup and Recovery Super Admin, Backup and Recovery Backup Admin Rolle. Wenn Daten geschützt werden, die auf einem Cloud Volumes ONTAP Cluster gespeichert sind, ist zusätzlich die Cloud Volumes ONTAP Admin-Rolle erforderlich. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Erfahren Sie mehr über die Zugriffsrollen der NetApp Console für alle Dienste"^].



[[protect-database-instances]]
=== Schützen Sie Datenbankinstanzen

Einer Datenbankinstanz wird eine Richtlinie zugewiesen, um den Zeitplan und die Aufbewahrung des Ressourcenschutzes zu steuern.

.Schritte
. Wählen Sie im NetApp Backup and Recovery -Menü *Inventar* aus.
. Wählen Sie die Arbeitslast aus, die Sie anzeigen möchten, und wählen Sie *Anzeigen*.
. Wählen Sie die Registerkarte *Instanzen*.
. Wählen Sie die Instanz aus.
. Wählen Sie die *Aktionen*image:icon-action.png["Symbol „Aktionen“"] Symbol und wählen Sie *Schützen*.
. Wählen Sie eine Richtlinie aus oder erstellen Sie eine neue.
+
Weitere Informationen zur Erstellung einer Richtlinie finden Sie unter link:br-use-policies-create.html["Erstellen einer Richtlinie"].

. Stellen Sie die Skripte bereit, die vor und nach der Datensicherung ausgeführt werden.
+
** *Vorskript*: Geben Sie den Dateinamen und den Speicherort des Skripts ein, das automatisch ausgeführt wird, bevor die Schutzaktion startet. Dies dient dazu, zusätzliche Aufgaben oder Konfigurationen vor dem Schutzworkflow vorzunehmen.
** *Nachtrag*: Geben Sie den Dateinamen und den Speicherort des Skripts ein, das nach Abschluss der Schutzmaßnahme automatisch ausgeführt wird. Dies kann verwendet werden, um nach dem Schutzworkflow zusätzliche Aufgaben oder Konfigurationen durchzuführen.


. Verifizierungsinformationen für den Snapshot angeben:
+
** Speicherort: Auswahl des Speicherorts für den Verifizierungs-Snapshot.
** Verifizierungsressource: Es kann ausgewählt werden, ob die Ressource im lokalen Snapshot, im ONTAP Sekundärspeicher oder in beiden überprüft wird.
** Überprüfungsplan: Die Häufigkeit kann ausgewählt werden: stündlich, täglich, wöchentlich, monatlich oder jährlich.
