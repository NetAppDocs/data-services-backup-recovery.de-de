= Kubernetes Schutzworkflow mit NetApp Backup und Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Backup und Recovery ermöglicht das Erkennen, Verwalten und Schützen von Kubernetes-Clustern und -Anwendungen über eine einzige Schnittstelle.

Das folgende Diagramm zeigt die Komponenten und die grundlegende Architektur für Kubernetes Backup und Recovery sowie die Möglichkeiten, Kopien Ihrer Daten an verschiedenen Orten zu speichern:

image:../media/backup-recovery-architecture-diagram.png["Architekturdiagramm der Sicherung und Wiederherstellung für Kubernetes-Workloads"]

NetApp Backup and Recovery bietet die folgenden Vorteile für die Verwaltung von Kubernetes-Workloads:

* Eine einheitliche Steuerungsebene zum Schutz von Anwendungen über mehrere Kubernetes-Cluster hinweg, einschließlich Containern und virtuellen Maschinen.
* Die native Integration mit NetApp SnapMirror ermöglicht die Auslagerung des Speichers für Backup und Recovery Workflows.
* Inkrementelle Dauersicherungen für Kubernetes-Anwendungen, was zu niedrigeren Recovery Point Objectives (RPOs) und Recovery Time Objectives (RTOs) führt.
