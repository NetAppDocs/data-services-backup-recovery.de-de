= NetApp Backup and Recovery IAM-Rollen
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Mit Identity and Access Management (IAM) lässt sich steuern, auf welche NetApp Backup and Recovery Funktionen und Aktionen jeder Benutzer zugreifen kann.

Informationen zu IAM-Rollen, die speziell für NetApp Backup and Recovery gelten, sind unter  https://docs.netapp.com/us-en/console-setup-admin/reference-iam-backup-rec-roles.html["NetApp Backup and Recovery -Rollen in der NetApp Console"^] zu finden.
