[[supported-systems-for-backup-and-restore-operations]]
== Unterstützte Systeme für Sicherungs- und Wiederherstellungsvorgänge

NetApp Backup and Recovery unterstützt ONTAP -Systeme sowie öffentliche und private Cloud-Anbieter.

=== Unterstützte Regionen

NetApp Backup and Recovery wird mit Cloud Volumes ONTAP in vielen Amazon Web Services-, Microsoft Azure- und Google Cloud-Regionen unterstützt.

[[supported-restore-destinations]]
=== Unterstützte Wiederherstellungsziele

Sie können Daten aus einer Sicherungsdatei, einer virtuellen Maschine, einer Datenbank oder einer Kubernetes-Ressource, die sich in einem sekundären System (einem replizierten Volume) oder in einem Objektspeicher (einer Sicherungsdatei) befinden, auf den folgenden Systemen wiederherstellen. Snapshots befinden sich auf dem Quellsystem und können nur auf demselben System wiederhergestellt werden.


NOTE: Wasabi ist derzeit der einzige qualifizierte S3-kompatible Objektspeicheranbieter. Andere S3-kompatible Anbieter wurden noch nicht validiert.

Bei der Wiederherstellung sind folgende Punkte zu beachten:

* Wiederherstellungen von Cloud Volumes ONTAP (Replikation) können nur auf Cloud Volumes ONTAP erfolgen. Cloud Volumes ONTAP in AWS unterstützt jedoch auch die Wiederherstellung auf Amazon FSx for NetApp ONTAP.
* Wiederherstellungen von lokalem ONTAP (Replikation) können nur auf lokales ONTAP durchgeführt werden.
* Wiederherstellungen von Amazon FSx for NetApp ONTAP und Google Cloud NetApp Volumes (Replikation) können nur auf dem jeweiligen First-Party-System durchgeführt werden.
* Die Wiederherstellung von Amazon S3 zu Amazon FSx for NetApp ONTAP muss in dieser Reihenfolge erfolgen: Amazon S3 zu Cloud Volumes ONTAP und dann Cloud Volumes ONTAP zu Amazon FSx for NetApp ONTAP.
