= Oracle Datenbank-Workloads mit NetApp Backup und Recovery schützen
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Backup und Recovery schützt Oracle Database Workloads und Protokolle mit schnellen, platzsparenden, absturzkonsistenten und datenbankkonsistenten Backups und Wiederherstellungen. Workloads können in AWS S3, StorageGRID, Azure Blob oder ONTAP S3 gesichert und Backups auf einem lokalen Oracle Host wiederhergestellt werden.

Mit NetApp Backup and Recovery lässt sich eine 3-2-1-Schutzstrategie implementieren, bei der drei Kopien der Quelldaten auf zwei verschiedenen Storage-Systemen sowie eine Kopie in der Cloud vorhanden sind. Die Vorteile des 3-2-1-Ansatzes sind:

* Mehrere Datenkopien schützen vor internen und externen Cybersicherheitsbedrohungen.
* Verschiedene Medientypen helfen Ihnen bei der Wiederherstellung, falls ein Typ ausfällt.
* Sie können die Wiederherstellung schnell von der Vor-Ort-Kopie durchführen und die Offsite-Kopien verwenden, wenn die Vor-Ort-Kopie kompromittiert ist.




[[oracle-data-guard-support]]
== Oracle Data Guard Unterstützung

NetApp Backup and Recovery kann Oracle Data Guard Konfigurationen mit einer primären Einzelinstanz-Datenbank und einer physischen Standby-Datenbank im gemounteten Zustand schützen.
